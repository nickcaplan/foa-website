# Link-action icon rule

- Match icons to link actions: every email/mailto link uses the existing envelope, phone/tel uses a phone, downloads use a download icon, external/new-tab links use the existing external arrow and accessible description, and internal navigation keeps its forward arrow; reuse site artwork/size/stroke, keep icons decorative, use the shared right-edge lane for structured buttons/rows and the final-word position for inline prose, and preserve explicitly approved social/calendar exceptions (Nick, 13 November 2026).
